[학교 기록관리 업무서식 파일 안내 및 사용자 임의 파일 추가 방법]

1. 본 폴더(public/forms/)는 웹 애플리케이션의 정적 자산(Static Assets) 저장 공간입니다.
2. 현재 내장된 표준 서식:
   - 기록물관리_책임자_지정통보서.xlsx
   - 기록물_반출입대장.xlsx
   - 비전자기록물_이관계획서.xlsx
   - 비전자기록물_인계인수서.xlsx

3. 임의의 파일(한글 HWP, PDF, Word, Excel 등)을 추가하여 다운로드받게 하는 방법:
   - 원하는 파일(예: "학교기록관리_자체지침.hwp", "이관계획서_서식.hwpx")을 이 public/forms/ 폴더 안에 복사해 넣습니다.
   - 웹 애플리케이션에서는 브라우저 주소 "/forms/파일명.확장자"를 통해 언제든지 파일이 직접 서비스됩니다.
   - 즉, <a href="/forms/학교기록관리_자체지침.hwp" download>다운로드</a> 버튼을 만들거나 링크를 걸면 원본 파일 그대로 다운로드됩니다.
